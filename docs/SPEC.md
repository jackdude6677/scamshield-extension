Build ScamShield, a free Chrome extension using Manifest V3 that protects elderly people from online scams. 1. Check visited URLs against a reputable phishing/malware threat database (e.g. Google Safe Browsing or free feeds like OpenPhish/PhishTank) using a secure architecture: a small proxy backend holds any API key, never exposed in the extension; prefer privacy-preserving lookups (hash prefixes). 2. Detect suspicious domain impersonation (lookalike/typosquat/homograph domains), fake bank login pages, and fake virus or tech-support alerts using conservative rules. 3. Show large, easy-to-read warnings explaining the specific risk, with Go Back, Why?, and an optional Continue Anyway choice. 4. Add a button to analyze pasted suspicious messages and links without automatically opening them. 5. Keep all user data private, request minimum browser permissions, use no paid services. 6. Never claim a website is safe just because no threat was found; avoid false alarms and test against a list of legitimate sites. 7. Polished, accessible interface (large text, high contrast, keyboard and screen reader friendly), automated tests, and packaged for local installation in Chrome (load unpacked, plus a zip) with install instructions.
